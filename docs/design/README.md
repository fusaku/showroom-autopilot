## 文档定位

本套文档描述现有录制上传系统，并为独立的成员管理与监控后台提供接入依据。不是部署执行指令，也不表示已经创建后台、变更数据库或验证服务器。

基线为 Git 提交 `1fbc859` 加当前工作区。包含本次公共文件锁和认证函数整理，以及工作区已有但未跟踪的管理脚本；不等同于两台服务器的当前版本。用户已确认两边采用完整项目同步方式。

证据分级：

- **代码确认**：当前工作区可以直接验证。
- **DDL 确认**：用户提供的结构定义已核对，不等同于实时数据库验证。
- **用户确认**：对话中明确提供的信息。
- **待核实**：依赖服务器、数据库元数据或运行日志，不能从代码确定。
- **规划**：独立后台的建议设计，尚未实现，不属于现有功能。

## 已确定的产品边界

1. 保留现有 Python 录制上传项目；新后台独立代码、环境和服务。
2. 后台主要提供成员管理及运行监控，不包含手动开始、停止录制。
3. 第一阶段只读；成员写入功能后续单独验证上线。
4. 后台故障不能成为原系统运行的前置条件；共享数据库和服务器仍存在资源耦合，不能承诺绝对零影响。
5. 删除成员优先设计为停用/后台归档；是否需要物理删除待表结构与历史关联确认。

## 维护规则
